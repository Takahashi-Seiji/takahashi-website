# Portfolio Website

A modern, responsive portfolio website built with Ruby on Rails and Tailwind CSS, showcasing my projects and skills.

## Features

- Responsive design that works on all devices
- Modern UI with smooth animations and transitions
- Project showcase section with interactive cards
- Skills and technology stack presentation
- Contact information and social links
- Clean and professional layout

## Technologies Used

- Ruby on Rails
- Tailwind CSS
- JavaScript
- HTML/ERB
- Docker
- PostgreSQL

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/Takahashi-Seiji/takahashi-website.git
cd takahashi-website
```

2. Install dependencies:
```bash
bundle install
```

3. Set up the database:
```bash
rails db:create db:migrate
```

4. Start the server:
```bash
bin/dev
```

5. Visit `http://localhost:3000` in your browser

## Development

This project uses:
- Ruby 3.x
- Rails 7.x
- Node.js
- Tailwind CSS for styling
- Docker for containerization
